# 附魔突破上限模块设计方案

## 1. 模块概述

**本文档为通用开发文档，不绑定特定版本，适用于多个Minecraft模组版本的开发。**

本模块通过Mixin技术实现Minecraft附魔等级突破功能，将原版255级限制提升至Int32最大值（2,147,483,647级），同时能够配合使用特性白名单模块中的自定义指令和白名单系统。

## 2. 核心功能

- 附魔等级上限提升至2,147,483,647级
- 可配置的最大附魔等级限制
- 可配置的生存模式铁砧附魔权限
- 可配置的附魔等级叠加机制
- 可配置的固定经验消耗
- `/wenxingtools cenchant` 自定义附魔指令（使用附魔ID，无物品类型限制，不受配置文件限制）
- 指令权限管理（白名单玩家/OP/创造模式均可使用）
- 白名单管理指令（add/remove/list）

```java
public abstract class ItemStackMixin {
    @Redirect(
            method = "enchant",
            at = @At(value = "INVOKE", target = "Lnet/minecraft/world/item/enchantment/Enchantment;getMaxLevel()I")

    private int modifyMaxEnchantmentLevel(Enchantment enchantment) {
```

```java
public abstract class AnvilMenuMixin extends ItemCombinerMenu {

    @ModifyVariable(
            method = "createResult",
            at = @At(value = "STORE"),
            ordinal = 0
    )
    private int modifyExperienceCost(int originalCost) {
        return ModConfig.fixedExperienceCost;

            method = "createResult",
            at = @At(value = "INVOKE", target = "Lnet/minecraft/world/item/enchantment/Enchantment;canEnchant(Lnet/minecraft/world/item/ItemStack;)Z")
```

### 4.5 权限控制 (PermissionUtil.java)

```java
public class PermissionUtil {
    public static boolean hasPermission(ServerPlayer player) {
        // 白名单玩家允许使用
        if (WhitelistManager.contains(player.getUUID())) return true;

        // 创造模式允许使用
        if (player.isCreative()) return true;

        // OP/权限等级2允许使用
        if (player.hasPermissions(2)) return true;

        return false;
    }
}
```

### 4.6 自定义指令 (ModCommands.java)

```java
@Mod.EventBusSubscriber(modid = WenXingToolsBase.MODID)
public class ModCommands {

    private static final SuggestionProvider<CommandSourceStack> ENCHANTMENT_SUGGESTIONS = (context, builder) -> {
        for (ResourceLocation id : BuiltInRegistries.ENCHANTMENT.keySet()) {
            builder.suggest(id.toString());
        }
        return builder.buildFuture();
    };

    @SubscribeEvent
    public static void onRegisterCommands(RegisterCommandsEvent event) {
        register(event.getDispatcher());
    }

    public static void register(CommandDispatcher<CommandSourceStack> dispatcher) {
        dispatcher.register(Commands.literal("wenxingtools")
                .requires(source -> {
                    try {
                        return source.getEntity() instanceof ServerPlayer && PermissionUtil.hasPermission((ServerPlayer) source.getEntity());
                    } catch (Exception e) {
                        return source.hasPermission(2);
                    }
                })

                // 白名单管理
                .then(Commands.literal("whitelist")
                        .then(Commands.literal("add")
                                .then(Commands.argument("target", EntityArgument.player())
                                        .executes(ctx -> addToWhitelist(ctx, EntityArgument.getPlayer(ctx, "target")))
                                )
                        )
                        .then(Commands.literal("remove")
                                .then(Commands.argument("target", EntityArgument.player())
                                        .executes(ctx -> removeFromWhitelist(ctx, EntityArgument.getPlayer(ctx, "target")))
                                )
                        )
                        .then(Commands.literal("list")
                                .executes(ModCommands::listWhitelist)
                        )
                )

                // 附魔指令（不受配置文件限制）
                .then(Commands.literal("cenchant")
                        .then(Commands.argument("targets", EntityArgument.entities())
                                .then(Commands.argument("enchantment", ResourceLocationArgument.id())
                                        .suggests(ENCHANTMENT_SUGGESTIONS)
                                        .executes(ctx -> executeCEnchant(ctx, EntityArgument.getEntities(ctx, "targets"), ResourceLocationArgument.getId(ctx, "enchantment"), 1))
                                        .then(Commands.argument("level", IntegerArgumentType.integer(1))
                                                .executes(ctx -> executeCEnchant(ctx, EntityArgument.getEntities(ctx, "targets"), ResourceLocationArgument.getId(ctx, "enchantment"), IntegerArgumentType.getInteger(ctx, "level")))
                                        )
                                )
                        )
                )
        );
    }

    private static int executeCEnchant(CommandContext<CommandSourceStack> ctx, Collection<? extends Entity> targets, ResourceLocation enchantmentId, int level) {
        Enchantment enchantment = BuiltInRegistries.ENCHANTMENT.get(enchantmentId);
        if (enchantment == null) {
            ctx.getSource().sendFailure(Component.literal("Invalid enchantment: " + enchantmentId).withStyle(ChatFormatting.RED));
            return 0;
        }

        // cenchant 指令不受配置文件限制，直接使用输入的等级
        final int actualLevel = level;
        int count = 0;
        for (Entity entity : targets) {
            if (entity instanceof LivingEntity living) {
                ItemStack stack = living.getMainHandItem();
                if (!stack.isEmpty()) {
                    stack.enchant(enchantment, actualLevel);
                    count++;
                }
            }
        }

        final int finalCount = count;
        if (finalCount > 0) {
            ctx.getSource().sendSuccess(() -> Component.literal("Enchanted " + finalCount + " item(s) with " + enchantment.getFullname(actualLevel).getString()).withStyle(ChatFormatting.GREEN), true);
        } else {
            ctx.getSource().sendFailure(Component.literal("No valid items found to enchant").withStyle(ChatFormatting.RED));
        }

        return finalCount;
    }
}
```

### 4.7 模组主类 (WenXingToolsBase.java)

```java
@Mod(WenXingToolsBase.MODID)
public class WenXingToolsBase {
    public static final String MODID = "wenxingtoolsbase";
    public static final Logger LOGGER = LogUtils.getLogger();

    public WenXingToolsBase() {
        IEventBus modEventBus = FMLJavaModLoadingContext.get().getModEventBus();
        modEventBus.addListener(this::commonSetup);
        MinecraftForge.EVENT_BUS.register(this);
    }

    private void commonSetup(final FMLCommonSetupEvent event) {
        event.enqueueWork(() -> {
            WhitelistManager.load();
            ModConfig.load();
        });
    }
}
```

## 5. 配置文件

### 5.1 wenxingtools.properties

```properties
#允许在生存模式下用铁砧为任何物品附魔
allowAnyEnchantment = true

#启用原版附魔等级叠加机制(例如:4+4=5，同级附魔+1级)
allowVanillaLevelStacking = true

#启用自定义附魔等级叠加机制(例如:4+4=8，取代原版的4+4=5)
allowLevelStacking = false

#最大附魔等级限制(范围:255至2147483647)
maxEnchantmentLevel = 10

#铁砧附魔或等级叠加的经验消耗都固定为1级经验
fixedExperienceCost = 1
```

## 8. 指令说明

### 8.1 权限说明

以下玩家可以使用指令：

- 在白名单中的玩家
- 创造模式玩家
- OP玩家（权限等级2）

### 8.2 指令列表

| 指令                                            | 说明                                                                                          |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `/wenxingtools cenchant <目标> <附魔ID> [等级]` | 为目标实体的手持物品附魔，附魔使用资源ID（如minecraft:sharpness），等级可选，不受配置文件限制 |
| `/wenxingtools whitelist add <玩家>`            | 将玩家添加到白名单                                                                            |
| `/wenxingtools whitelist remove <玩家>`         | 将玩家从白名单移除                                                                            |
| `/wenxingtools whitelist list`                  | 查看白名单列表                                                                                |

## 9. 设计原则

- **最小化修改**：使用Mixin精确注入，避免大面积修改原版代码
- **Core/Adapter分层**：配置逻辑与Mixin注入分离
- **可配置性**：所有核心功能通过配置文件控制
- **兼容性**：保留原版指令功能，仅扩展新特性
